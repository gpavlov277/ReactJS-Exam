This project aims to create an React application for a vehicle or a post social media website. The application will have various features to showcase and edit for different vehicles. Users will be able to view vehicles (items), create or edit vehicle and delete it (if they are owners), like or comment.

    Header Component: Develop a header component that will be displayed on all pages of the application. This component will contain HTML markup and CSS styles to create an appealing and consistent header.
    Listing Vehicles (posts or items): Create list component where all users can see vehicles added to the database. Guest users also can see available vehicles.
    Edit vehicle: Develop an edit page where Logged in users (owners) can edit current selected vehicle. Here usesr can only change vehicle's image or some fields.
    Delete functuinality: Simple pop-up window where user can choose to delete current vehicle or not. Only logged in users can access that functionality.
    Likes: Authrenticated users are able to like vehicles by clicking arrow up button at the details page of the application.
    Settings page where current user can se information about profile (created posts, total comments).
